Inside the Intelligence

The Machine Learning Workflow

How MedRecSys transforms discrete symptom observations into structured medical predictions.

1

Symptom Ingestion & Tokenization

User selects or types symptoms; values are sanitized, deduplicated, and mapped to standard medical identifiers.

2

Binary Feature Vectorization

An array of 131 binary flags (0 or 1) is constructed representing the presence or absence of each clinical symptom.

3

Support Vector Machine Inference

The pre-trained linear/RBF kernel evaluates the symptom vector across multidimensional hyperplanes to predict the target disease.

4

Medical Knowledge Base Query

The predicted condition acts as a primary key to fetch associated clinical precautions, diets, medications, and workouts.

5

Structured Health Report Synthesis

The client renders a responsive report with confidence assessment, clear safety reminders, and doctor consultation guidance.

Classification Model

Support Vector Classifier (SVC)

Support Vector Machines are effective in high-dimensional feature spaces where the number of dimensions exceeds common observation counts. In MedRecSys, SVC maximizes the margin between different disease clusters, ensuring robust classification even with sparse symptom combinations.

Clean, Transparent Engineering

A look inside the symptom vectorization and classification logic powering MedRecSys.

medrecsys/ml_inference.py
Python 3.10
# MedRecSys: High-Dimensional Vectorization & SVC Inference
import pickle
import numpy as np

# 1. Load pre-trained Support Vector Classifier
with open('svc.pkl', 'rb') as f:
    svc_model = pickle.load(f)

def predict_disease(user_symptoms, symptom_dictionary):
    """Encode 131 clinical features into binary vector and run inference"""
    feature_vector = np.zeros(len(symptom_dictionary), dtype=int)
    for symptom in user_symptoms:
        if symptom in symptom_dictionary:
            feature_vector[symptom_dictionary[symptom]] = 1

    # Run deterministic prediction across separating hyperplanes
    predicted_class = svc_model.predict([feature_vector])[0]
    return predicted_class
