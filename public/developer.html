Developer

Project and technical overview

This page keeps the development details separate from the user-facing prediction and contact pages while preserving the same blue and light-red theme.

Backend

Node.js HTTP server

The app serves static pages, handles symptom prediction requests, and sends realtime mail through Gmail SMTP.

Frontend

Separate page structure

The interface is split across Home, Predict, Results, Developer, and Contact pages with one shared theme and navigation.

Dataset

CSV powered recommendations

Prediction and supporting advice are generated from the local medical CSV files already present in the project.

Current stack

HTML, CSS, JavaScript, Node.js

The current working version uses plain HTML, shared CSS, vanilla JavaScript, and a lightweight Node.js server without adding a framework.

Mail flow

Realtime contact delivery

The contact form submits to the Node backend, which validates the request and sends the mail directly to your configured inbox.
